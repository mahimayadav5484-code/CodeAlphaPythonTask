## Requirements

- Python 3.x (no external libraries needed)

---

## Task 1: Hangman Game (`hangman.py`)

A simple text-based Hangman game. The computer picks a random word from a list of 5 predefined words, and the player guesses one letter at a time. The player is allowed 6 incorrect guesses.

- **Concepts used:** `random`, `while` loop, `if-else`, strings, lists
- **Run:** `python hangman.py`

## Task 2: Stock Portfolio Tracker (`stock_tracker.py`)

A console program that lets the user enter stock names and quantities, then calculates the total investment using a hardcoded dictionary of stock prices. The result is also saved to `portfolio_result.txt`.

- **Concepts used:** dictionary, input/output, basic arithmetic, file handling
- **Run:** `python stock_tracker.py`
- **Example prices:** `AAPL: 180`, `TSLA: 250`, `GOOGL: 140`, `MSFT: 330`, `AMZN: 125`

## Task 3: Task Automation, Email Extractor (`task_automation.py`)

A script that automates a repetitive task: it reads a `.txt` file, extracts all email addresses using regular expressions, removes duplicates, and saves them to `extracted_emails.txt`. If the input file is missing, a sample file is created automatically.

- **Concepts used:** `re`, `os`, file handling, lists
- **Run:** `python task_automation.py`

## Task 4: Basic Chatbot (`chatbot.py`)

A rule-based chatbot that replies to user inputs such as "hello", "how are you" and "bye" with predefined responses. Type `bye` to exit.

- **Concepts used:** `if-elif`, functions, loops, input/output
- **Run:** `python chatbot.py`
